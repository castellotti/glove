- `ssh <host> <command>` works from shell commands, to this session's hosts only ({% for h in settings.hosts %}`{{ h.name }}`{% if not loop.last %}, {% endif %}{% endfor %}). It is relayed to a sidecar that holds the key, so you never see the key and no other shell command has network. There is no interactive shell, no TTY and no stdin: pass the whole command (`ssh {{ settings.hosts[0].name }} 'uname -a && df -h'`). Port forwarding, jump hosts, `-i`/`-F` and other hosts are refused; host keys are checked strictly against the session's known_hosts.
